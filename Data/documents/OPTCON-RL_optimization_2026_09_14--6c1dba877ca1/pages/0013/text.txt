Equality constraints and convex sets
Let h : Rd →Rp, we can define a set Zeq ⊂Rd as
Zeq = {z ∈Rd | h(z) = 0}
The set Zeq is convex if and only if h is an affine function. Convex sets identified through equality
constraints are linear spaces (hyperplanes).

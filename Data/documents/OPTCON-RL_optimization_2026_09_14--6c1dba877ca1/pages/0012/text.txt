Inequality constraints and convex sets
Let g : Rd →Rp, we can define a set Zineq ⊂Rd as
Zineq = {z ∈Rd | g(z) ≤0}
The set Zineq is convex if and only if g is a quasi-convex function (e.g., monotone functions on the axis).
Corollary: If g is convex, then Zineq is convex.
